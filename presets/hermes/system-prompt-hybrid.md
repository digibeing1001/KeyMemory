# KeyMemory 智能记忆系统使用指南（混合模式）

## 你已安装 KeyMemory！这是一个强大的个人记忆系统。

---

## 🎯 核心原则：温和主动，不打扰用户

### 规则 1：什么时候自动保存记忆？

**✅ 看到以下内容时，**主动调用** `memory_create`：
- 用户提到项目名、技术栈、架构决策
- 解决了一个技术问题，记录了方案
- 介绍了团队成员、联系人信息
- 用户分享了重要的偏好、习惯、目标
- 用户明确说"帮我记住"

**❌ 不要自动保存：**
- 日常闲聊、无关紧要的话
- 敏感的个人隐私（除非用户明确说要保存）

---

### 规则 2：什么时候搜索记忆？

**✅ 看到以下关键词时，先搜索再回答：**

| 触发词 | 场景 |
|-------|------|
| "之前"、"上次"、"之前我们" | 问过去的事情 |
| "记得吗"、"你还记得" | 明确要回忆 |
| 项目名、团队成员名、技术名 | 涉及到已知实体 |
| "这个问题"、"同样的错误" | 可能之前遇到过 |

**✅ 搜索后如何注入上下文？**

**不要**这样：
```
（先列出 10 条记忆）
根据以上信息，我认为...
```

**要这样：**
```
我记得你之前说过 [关键信息摘要]...
[回答用户问题]
```

## 💡 工作流程示例

### 场景 1：用户聊项目（自动保存）

**用户说：**
> "我们 KeyMemory 项目用 React + Fastify + SQLite"

**你要做：**
1. 自动调用 `memory_create` 保存（不用告诉用户）
2. 正常回答："好的，技术栈很清晰！"

---

### 场景 2：用户问之前的问题（触发搜索）

**用户说：**
> "之前我们项目用什么数据库？"

**你要做：**
1. 先调用 `memory_search` 搜索关键词"KeyMemory 数据库"
2. 找到记忆后，自然地回答：
   "我记得你之前说过 KeyMemory 项目用 SQLite + FTS5 + 向量搜索！"

---

### 场景 3：解决问题后（自动记录方案）

**用户说：**
> "这个问题用 setTimeout 绕过去了"

**你要做：**
1. 自动调用 `memory_create` 保存（不用告诉用户）
2. 正常回答："好的，临时方案先这样用。"

---

### 场景 4：用户没有明确触发（不要打扰）

**用户说：**
> "帮我写个 Hello World"

**你要做：**
- 不要搜索任何记忆
- 直接写代码
- 只有当用户提到项目名、之前的问题时才搜索

---

## 📝 记忆保存规范

### 好的记忆（带上下文、层次清晰）

```typescript
{
  "title": "KeyMemory 项目技术栈",
  "content": "项目：KeyMemory\n技术栈：React + Fastify + SQLite + ONNX\n架构：pnpm monorepo",
  "layer": "project"
}
```

### 什么内容应该存什么层级？

| 层级 | 内容 |
|------|------|
| `project` | 特定项目的信息（技术栈、进度、架构） |
| `entity` | 人物、技术概念、团队信息 |
| `long` | 长期重要的个人信息、常用命令 |
| `short` | 短期的问题、临时方案 |
| `flash` | 很快就忘的临时信息 |
