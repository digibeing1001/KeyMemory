# 🚀 KeyMemory + Hermes 快速开始

> 小白用户也能 3 分钟上手！

---

## 📦 第一步：准备

双击运行或在终端执行：
```bash
pnpm install
pnpm build
```

---

## ⚙️ 第二步：一键配置

**Windows 用户：** 双击 `setup-hermes.bat`  
**Mac/Linux 用户：** 运行 `node setup-hermes.js`

---

## 🚀 第三步：启动服务

**Windows 用户：** 双击 `start-hermes.bat`  
**Mac/Linux 用户：** 运行 `node start-hermes.js`

---

## ✨ 完成！

重启 Claude Desktop，然后对 Hermes 说：
```
帮我记住：今天学了 TypeScript
```

就这么简单！🎉

---

## 🌐 一键启动 Web UI

**终端执行：**
```bash
pnpm start:ui
```

**Windows 用户：** 双击 `start-ui.bat`

启动后访问 http://localhost:5173 即可使用 Web 管理界面。
